# دوري رواء — تطبيق إدارة النادي 🏀

تطبيق ويب لإدارة نادٍ فيه **3 فرق** (بؤرة • الرواد • الفهود، 6-8 لاعبين لكل فريق)، مع نظام **ميزانيات**،
تسجيل **مباريات** يحسب الفلوس تلقائيًا، **سوق انتقالات (مزاد)**، وبطاقات لاعبين
بطاقاتهم (نمط FIFA). كل البيانات تُحفظ محليًا في المتصفح — **بدون خادم ولا تسجيل دخول**.

## التشغيل

لا يحتاج أي تثبيت أو أدوات بناء:

- **الأسهل:** افتح ملف `index.html` مباشرة في المتصفح.
- **أو** شغّل خادمًا محليًا: `python3 -m http.server` ثم افتح `http://localhost:8000`.
- **للنشر مجانًا:** فعّل **GitHub Pages** على هذا المستودع (Settings → Pages → Branch)،
  وبيصير للتطبيق رابط تفتحه من أي جوال أو كمبيوتر.

## الأدوار وتسجيل الدخول 🔐

عند فتح التطبيق تظهر شاشة دخول فيها **ثلاثة استخدامات**:

| الدور | الصلاحيات | الدخول |
|---|---|---|
| 🛡️ **المشرف المسؤول** | كامل التحكم (الفرق، اللاعبون، المباريات، السوق، الحسبة، الإعدادات، جدول المباريات القادمة، وكلمات المرور) | كلمة مرور المشرف |
| 🎽 **رئيس النادي** (لكل فريق) | شغلتان فقط: **المزايدة** على اللاعبين بفريقه في السوق، و**بناء تشكيلة** فريقه لكل مباراة **وتصديرها صورة PNG** | يختار ناديه + كلمة مروره |
| 👁️ **عرض عام** | صفحة قراءة فقط: الترتيب، الفرق واللاعبون، النتائج، المباريات القادمة، الميزانيات | بدون دخول |

**كلمات المرور الافتراضية** (يغيّرها المشرف من الإعدادات): المشرف `admin` •
بؤرة `1111` • الرواد `2222` • الفهود `3333`.

> الحماية هنا على **مستوى الواجهة** فقط (قاعدة البيانات مفتوحة حاليًا). كلمات المرور تُحفظ
> ضمن حالة التطبيق. لحماية حقيقية يلزم لاحقًا تفعيل قواعد أمان/تسجيل دخول في Firebase.

## المباريات القادمة والتشكيلات

- **المباريات القادمة:** يديرها المشرف (إضافة/تعديل/حذف، وتعليمها «أُقيمت»)، وتظهر للجميع في الصفحة العامة.
- **التشكيلة:** يبنيها رئيس النادي على **ملعب بخطة ومراكز** (2-2-1، 3-2-1، …)، يوزّع لاعبيه على المراكز،
  ثم **يصدّرها صورة PNG** جاهزة للمشاركة (ترسم عبر canvas بدون أي مكتبات خارجية).

## المزايا الحالية

| القسم | الوصف |
|---|---|
| 🏠 الرئيسية | ميزانيات الفرق، جدول الترتيب، إجراءات سريعة، إدارة الأسبوع |
| 🛡️ الفرق | تعديل الفرق (الاسم/اللون/القائد)، عرض لاعبي كل فريق |
| 🎽 اللاعبون | إضافة/تعديل لاعب، بطاقته وتقييمه، **تقييم الأداء** وسجل الحسبة |
| ⚽ المباريات | تسجيل مباراة بأحداثها → حساب الفلوس والنتيجة تلقائيًا |
| 💰 السوق | مزاد نهاية الأسبوع: اختيار لاعبين (عشوائي/يدوي) ومزايدة الفرق |
| 📒 الحسبة | سجل كل الحركات المالية + تصدير/استيراد نسخة احتياطية |
| ⚙️ الإعدادات | تعديل معايير الفلوس وأسماء الطاقات واسم النادي |

## معايير التقييم (طاقة اللاعب)

يبدأ كل لاعب من **50** وسقفه **99** (وأرضيته 0). المسؤول يدخل عدد أحداث اللاعب،
والنظام يحسب الفرق ويطبّقه على تقييمه **مع حفظ سجل الحسبة** (كيف تغيّر التقييم).

| للجميع | نقاط | | للحارس | نقاط |
|---|---|---|---|---|
| هدف | +10 | | تصدّي ناجح | +3 |
| تمرير ناجح | +1 | | شباك نظيفة | +10 |
| صناعة | +7 | | | |
| قطع الكرة | +2 | | | |
| تصدّي كرة على المرمى (غير الحارس) | +5 | | | |

**الخصومات:** بطاقة صفراء −5 • بطاقة حمراء −13 • تسبب بلنتي −7 • هدف عكسي −10 •
إضاعة فرصة محققة −4 • تسبب بفاول خطير −4 • تسبب بخطأ عمومًا −2 • استقبال هدف −3

كل هذه القيم **قابلة للتعديل** من الإعدادات.

## المزامنة السحابية (Firebase Realtime Database)

التطبيق مربوط بـ Firebase: كل التعديلات تُزامَن لحظيًا بين كل الأجهزة (كل الأعضاء
يشوفون نفس البيانات). يظهر مؤشّر حالة المزامنة أعلى الشاشة (متصل ☁ / محلي / غير متصل).
لو انقطع الإنترنت أو تعذّر الاتصال، يعمل التطبيق محليًا ويعيد المزامنة عند الرجوع.

- الإعدادات في `assets/firebase-config.js` (مفاتيح عامة آمنة للعميل).
- لتعطيل السحابة والعمل محليًا فقط: اجعل `window.DAWRI_FIREBASE_CONFIG = null`.
